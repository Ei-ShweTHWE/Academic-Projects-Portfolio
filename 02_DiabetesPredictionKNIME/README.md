# 02 - Diabetes Prediction Using Machine Learning in KNIME

## 📌 Project Overview
A master's coursework project focusing on developing an end-to-end machine learning pipeline in KNIME to predict diabetes risks using clinical data.

## 🛠️ Data Pipeline & Preprocessing
* **Data Ingestion & Exploration:** Executed data loading, missing value handling, and exploratory data analysis (EDA) on a clinical dataset of 768 patient records and 8 clinical features.

## 🔬 Feature Analysis & Modeling
* **Feature Engineering:** Implemented linear correlation, feature engineering, and a 70/30 data partitioning strategy.
* **Algorithm Deployment:** Deployed a Random Forest algorithm (Random Forest Learner & Predictor) to handle missing data and mitigate overfitting through ensemble learning.

## 📊 Evaluation & Findings
* **Performance Assessment:** Evaluated model performance using Scorer nodes and ROC curves.
* **Key Indicators:** Identified Glucose, BMI, and age as the strongest predictive indicators for early medical intervention.
