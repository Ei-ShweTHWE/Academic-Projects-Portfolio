# Academic Projects Portfolio 🎓🚀

This repository showcases a curated collection of master's coursework and field projects completed at the International School of Management (ISM). It demonstrates practical applications across data science, business intelligence, machine learning, agile project management, and process optimization.

## 📁 Projects Overview
1. **01_AIAssistantAgileProject:** Collaborative team project focused on agile execution, Scrum methodologies, stakeholder management, and NPV-focused budgeting for an AI-driven academic assistant.
2. **02_Diabetes Prediction in KNIME:** End-to-end machine learning pipeline leveraging Random Forest algorithms, data preprocessing, and ROC curve evaluations for clinical risk prediction.
3. **03_VolkswagenBPMNTransformation:** Individual process management project analyzing EV transition goals and designing multi-pool BPMN workflows across procurement, production, and logistics.
4. **04_GoldenWaveKnowledgeTransferTool:** Field project based on a business case from OMM, featuring a 6-week implementation roadmap for an AI-powered knowledge transfer tool.
5. **05_EarthquakePredictionR:** Statistical forecasting and predictive modeling project using RStudio to analyze historical earthquake data through multiple linear regression and back-testing metrics.
