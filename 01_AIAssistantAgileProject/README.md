# 01 - AI Assistant for University Students (Agile Project Plan)

## 📌 Project Overview
A master's coursework collaborative team project focusing on leading the planning and agile execution of an AI-driven academic assistant designed to provide 24/7 personalized support for university students.

## 🛠️ Key Frameworks & Methodologies
* **Agile & Scrum Execution:** Implemented Scrum methodologies with 2-week sprint cycles, backlog prioritization, and continuous feedback loops.
* **Stakeholder & Security Management:** Coordinated cross-functional requirements across academic staff, IT security, and management, ensuring robust data privacy, encryption, and NPV-focused budget control.
* **Risk Mitigation Strategy:** Designed proactive mitigation strategies for AI errors (human-in-the-loop review) and integration challenges (modular API architecture).

## 🎯 Key Achievements & Outcomes
* Successfully delivered a comprehensive agile project execution plan balancing technical feasibility, data security, and budget constraints for academic integration.
