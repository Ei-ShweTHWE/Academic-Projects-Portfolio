# 01 - AI Assistant for University Students (Agile Project Plan)

## 📌 Project Overview
A master's coursework collaborative team project focused on leading the planning and agile execution of an AI-driven academic assistant designed to provide 24/7 personalized support for university students[cite: 1].

## 🛠️ Key Frameworks & Methodologies
* **Agile & Scrum Execution:** Implemented Scrum methodologies with 2-week sprint cycles, strict backlog prioritization, and continuous feedback loops[cite: 1].
* **Stakeholder & Security Management:** Coordinated cross-functional requirements across academic staff, IT security, and management, ensuring robust data privacy, encryption, and NPV-focused budget control[cite: 1].
* **Risk Mitigation Strategy:** Designed proactive mitigation frameworks for AI errors (incorporating human-in-the-loop reviews) and integration challenges (modular API architecture)[cite: 1].

## 🎯 Key Achievements & Outcomes
* Successfully delivered a comprehensive agile project execution plan balancing technical feasibility, data security, and budget constraints for academic integration.
