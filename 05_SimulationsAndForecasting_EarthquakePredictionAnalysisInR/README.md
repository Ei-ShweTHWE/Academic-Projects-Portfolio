# 05 - Simulations and Forecasting: Earthquake Prediction Analysis in R

## 📌 Project Overview
A master's coursework project focusing on simulation, exploratory data analysis, and predictive modeling in RStudio to analyze earthquake frequencies and magnitudes in Kyrgyzstan (2014-2024).

## 🛠️ Data Pipeline & Exploratory Data Analysis (EDA)
* **Data Processing:** Processed 10 years of historical earthquake data, executing data cleaning, outlier checks, feature correlation, and pairwise scatter plots.
* **Time-Series Decomposition:** Analyzed temporal patterns through trend, seasonal, and residual decomposition.

## 📈 Predictive Modeling
* **Regression Models:** Built and evaluated both Simple Linear Regression and Multiple Linear Regression models (incorporating depth, location, and time variables) to predict earthquake magnitudes.

## 🎯 Evaluation & Back-Testing
* **Performance Validation:** Conducted rigorous back-testing on a test period (2023-2024) using training data from 2014-2022.
* **Accuracy Metrics:** Evaluated performance using RMSE, MAPE, MAE, and R-squared metrics to compare baseline trends and prediction accuracy.
